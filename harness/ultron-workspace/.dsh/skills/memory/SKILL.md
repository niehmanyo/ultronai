# Controlled personal memory

Use memory/approved.md in the active workspace. It begins empty.

Only save memory with explicit user approval; show the exact proposed fact, its source and intended scope first. Inspect the file after writing. Corrections and deletion require precise entry identification and confirmation.

Never put API keys, passwords or authentication tokens into a memory file. This is a transparent file-backed starter, not automatic semantic retrieval or embedding-based Memory V2.
